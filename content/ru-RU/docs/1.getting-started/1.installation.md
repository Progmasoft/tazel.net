Tazel — программа на Kotlin для JVM, поэтому машине нужна среда Java 25 или новее. Сам он ничего не компилирует:
`check`, `build`, `run` и `test` запускают Talac, `fmt` запускает talafmt, а `lint` — talalint.

## Сборка Tazel

Tazel собирается из исходного кода обёрткой Gradle, которой нужен JDK 25. `installDist` записывает запускающие файлы
`tazel` и `tazel.bat` в `build/install/tazel/bin`. Добавьте эту папку в `PATH`.

```bash [Linux и macOS]
git clone https://github.com/Progmasoft/tazel.git
cd tazel
./gradlew installDist
```

```powershell [Windows]
git clone https://github.com/Progmasoft/tazel.git
cd tazel
.\gradlew.bat installDist
```

`tazel version` выводит установленную версию.

## Инструменты Tala

Каждый инструмент Tazel ищет через `TAZEL_TALAC`, `TAZEL_TALAFMT` или `TAZEL_TALALINT`, затем в своей установке, затем
в `PATH`. У каждого инструмента свои выпуски:

| Инструмент | Нужен для                       | Исходный код                                                  |
| ---------- | ------------------------------- | ------------------------------------------------------------- |
| Talac      | `check`, `build`, `run`, `test` | [Progmasoft/tala](https://github.com/Progmasoft/tala)         |
| talafmt    | `fmt`                           | [Progmasoft/talafmt](https://github.com/Progmasoft/talafmt)   |
| talalint   | `lint`                          | [Progmasoft/talalint](https://github.com/Progmasoft/talalint) |

Проект — это папка с файлом проекта. Его исходники — файлы `.tala` в `Sources/`, а `entry` называет класс, чей
`public static void Main()` запускает программу.

```kotlin [BUILD.kts]
project {
  name = "Example"
}

sources {
  executable {
    entry = "Example.Program"
  }
}
```

```tala [Sources/Main.tala]
namespace Example;

public class Program {
    public static void Main() {
        Console.Println("Hello from Tala!");
    }
}
```

## Сборка и запуск

```bash [terminal]
tazel build
tazel run -- first second
```

`tazel build` записывает `build/debug/Example`, в Windows — `Example.exe`. `tazel run` собирает программу и запускает
её; всё после `--` без разбора передаётся программе. Повторный `tazel build` без изменений сообщает, что цель актуальна,
и не запускает компилятор.

## Форматирование и проверка

```bash [terminal]
tazel fmt -- --check
tazel lint -- --fix
```

Параметры после `--` передаются talafmt и talalint, поэтому `tazel fmt -- --check` только сообщает, а
`tazel lint -- --fix` применяет исправления, какие может.

::note
ViGet не раздаёт пакеты Tala. Проект, объявляющий зависимость сборки, библиотечные цели и создание `.vipkg` отклоняются
по имени с кодом выхода 1.
::

Tazel ist ein Kotlin-Programm für die JVM, ein Rechner braucht also eine Java-Laufzeit 25 oder neuer. Es kompiliert
selbst nichts: `check`, `build`, `run` und `test` starten Talac, `fmt` startet talafmt und `lint` startet talalint.

## Tazel bauen

Tazel wird aus seinem Quellcode mit dem Gradle-Wrapper gebaut, der ein JDK 25 braucht. `installDist` schreibt die
Starter, `tazel` und `tazel.bat`, nach `build/install/tazel/bin`. Nehmen Sie diesen Ordner in `PATH` auf.

```bash [Linux und macOS]
git clone https://github.com/Progmasoft/tazel.git
cd tazel
./gradlew installDist
```

```powershell [Windows]
git clone https://github.com/Progmasoft/tazel.git
cd tazel
.\gradlew.bat installDist
```

`tazel version` gibt die installierte Version aus.

## Die Tala-Werkzeuge

Tazel findet jedes Werkzeug über `TAZEL_TALAC`, `TAZEL_TALAFMT` oder `TAZEL_TALALINT`, dann in seiner eigenen
Installation, dann über `PATH`. Jedes Werkzeug hat eigene Releases:

| Werkzeug | Verwendet von                   | Quellcode                                                     |
| -------- | ------------------------------- | ------------------------------------------------------------- |
| Talac    | `check`, `build`, `run`, `test` | [Progmasoft/tala](https://github.com/Progmasoft/tala)         |
| talafmt  | `fmt`                           | [Progmasoft/talafmt](https://github.com/Progmasoft/talafmt)   |
| talalint | `lint`                          | [Progmasoft/talalint](https://github.com/Progmasoft/talalint) |

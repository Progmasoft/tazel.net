פרויקט הוא תיקייה עם קובץ פרויקט בשם `BUILD.kts`, ‏`BUILD.tzl`, ‏`BUILD.tazel`, ‏`BUILD` או `Tazel.build`. הפרויקט
הזה בונה תוכנית Tala: המקורות שלו הם קובצי `.tala` שמתחת ל-`Sources/`, ו-`entry` מציין את המחלקה
שה-`public static void Main()` שלה מפעיל את התוכנית. פרויקט ב-C או ב-C++ משתמש במקום זאת בבלוק `cc { }` של
[התוסף](/docs/extending/plugins) Progmasoft.CC, ולא צריך אף כלי של Tala.

```kotlin [BUILD.kts]
project {
  name = "Example"
}

sources {
  executable {
    entry = "Example.Program"
  }
}
```

```tala [Sources/Main.tala]
namespace Example;

public class Program {
    public static void Main() {
        Console.Println("Hello from Tala!");
    }
}
```

## בנייה והרצה

```bash [terminal]
tazel build
tazel run -- first second
```

‏`tazel build` כותבת את `build/debug/Example`, וב-Windows את `Example.exe`. ‏`tazel run` בונה את התוכנית ומפעילה
אותה; מה שאחרי `--` עובר לתוכנית בלי קריאה. ‏`tazel build` שנייה בלי שינוי מדווחת שהיעד עדכני ולא מפעילה מהדר.

## עיצוב וניתוח

```bash [terminal]
tazel fmt -- --check
tazel lint -- --fix
```

אפשרויות אחרי `--` עוברות ל-talafmt ול-talalint, כך ש-`tazel fmt -- --check` רק מדווחת, ו-`tazel lint -- --fix`
מחילה את התיקונים שהיא יכולה.

::note
‏ViGet לא מגישה חבילות של Tala. פרויקט שמצהיר על תלות של הבנייה, יעדי ספרייה ויצירת `.vipkg` נדחים בשמם עם קוד
יציאה 1.
::

‏Tazel היא תוכנית Kotlin ל-JVM, ולכן מחשב צריך סביבת Java בגרסה 25 ומעלה. היא עצמה לא מהדרת דבר: `check`, `build`,
`run` ו-`test` מפעילות את Talac, ‏`fmt` מפעילה את talafmt ו-`lint` מפעילה את talalint.

## בניית Tazel

‏Tazel נבנית מקוד המקור שלה בעזרת עטיפת Gradle, שצריכה JDK 25. ‏`installDist` כותבת את קובצי ההפעלה `tazel`
ו-`tazel.bat` אל `build/install/tazel/bin`. הוסיפו את התיקייה הזאת ל-`PATH`.

```bash [Linux ו-macOS]
git clone https://github.com/Progmasoft/tazel.git
cd tazel
./gradlew installDist
```

```powershell [Windows]
git clone https://github.com/Progmasoft/tazel.git
cd tazel
.\gradlew.bat installDist
```

‏`tazel version` מדפיסה את הגרסה המותקנת.

## הכלים של Tala

‏Tazel מוצאת כל כלי דרך `TAZEL_TALAC`, ‏`TAZEL_TALAFMT` או `TAZEL_TALALINT`, אחר כך בהתקנה שלה עצמה, ואחר כך
ב-`PATH`. לכל כלי יש גרסאות משלו:

| כלי      | בשימוש של                       | קוד מקור                                                      |
| -------- | ------------------------------- | ------------------------------------------------------------- |
| Talac    | `check`, `build`, `run`, `test` | [Progmasoft/tala](https://github.com/Progmasoft/tala)         |
| talafmt  | `fmt`                           | [Progmasoft/talafmt](https://github.com/Progmasoft/talafmt)   |
| talalint | `lint`                          | [Progmasoft/talalint](https://github.com/Progmasoft/talalint) |

A version of Tazel has four numbers: `MAJOR.SEMIMAJOR.MINOR.PATCH`, such as `0.4.0.3`. Every release has a tag
`tazel-<version>` and release notes on [GitHub](https://github.com/Progmasoft/tazel/releases).

## Three kinds of release

| Kind | Supported for | Which releases |
| --- | --- | --- |
| Rolling | 6 months | every release that is not LTS or ELTS, and every release before `1.0.0.0` |
| LTS (Long-Term Support) | 5 years | the line `A.0` of each `MAJOR` from `1.0.0.0` on |
| ELTS (Extended Long-Term Support) | 12 years | the LTS line of `MAJOR` 1, 4, 7 and every third after them |

The time counts from the first release of the line. A supported line receives fixes for bugs and for security
problems as new `MINOR` and `PATCH` releases; it receives no new features, which come in the Rolling releases.

## Which one to use

- **Rolling** brings each feature first. Take the newest release; the one before it stays supported for 6 months.
- **LTS** stays on one line for 5 years, for projects that upgrade once in a while.
- **ELTS** stays on one line for 12 years, for products that are built with Tazel for a long time.

Every release of Tazel before `1.0.0.0` is Rolling.
